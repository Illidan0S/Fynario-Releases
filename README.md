# Fynario Releases

Canale pubblico ufficiale per i metadati e gli artefatti delle release di Fynario.

Il codice sorgente dell'applicazione non è pubblicato in questo repository.

## Stable channel

Fynario Mobile consulta la release GitHub stabile più recente e legge l'asset `fynario-update.json` per verificare se è disponibile una versione più nuova e compatibile.

Gli artefatti pubblicati qui non contengono credenziali, chiavi di firma o altri segreti.
